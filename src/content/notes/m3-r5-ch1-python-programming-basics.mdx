## 1. Problem Solving Concepts (समस्या समाधान अवधारणाएं)

Before writing code, a programmer designs the logic using two primary tools:
1. **Algorithm (एल्गोरिदम):** A step-by-step finite sequence of instructions written in plain English to solve a specific problem.
2. **Flowchart (फ्लोचार्ट):** A graphical representation of an algorithm using standard geometric symbols.

### Standard Flowchart Symbols (मानक फ्लोचार्ट प्रतीक)
- **Oval / Pill:** Start / End (टर्मिनल)
- **Parallelogram:** Input / Output (डेटा इनपुट या आउटपुट)
- **Rectangle:** Process / Calculation (प्रक्रिया या गणना)
- **Diamond:** Decision / Condition (निर्णय - If/Else)
- **Arrows:** Flow lines (डेटा का प्रवाह)
- **Circle:** Connector (कनेक्टर)

## 2. Introduction to Python (पायथन का परिचय)

- **Creator:** Developed by **Guido van Rossum** at CWI (Centrum Wiskunde & Informatica) in the Netherlands.
- **Release Date:** February 1991.
- **Name Origin:** Named after the BBC comedy television show *"Monty Python's Flying Circus"*.
- **Language Paradigm:** High-level, Interpreted, Object-Oriented, Dynamically Typed, and Open Source.

## 3. Key Differences: Compiler vs Interpreter

| Feature | Compiler (कंपाइलर) | Interpreter (इंटरप्रेटर - Python) |
| :--- | :--- | :--- |
| **Execution** | Translates the whole program at once | Translates code line-by-line |
| **Error Reporting** | Displays all errors after scanning complete code | Stops execution immediately upon encountering an error |
| **Intermediate Object** | Generates standalone `.exe` or binary | Generates bytecode (`.pyc`) dynamically executed by PVM |
| **Examples** | C, C++, Rust | Python, JavaScript, Ruby |
