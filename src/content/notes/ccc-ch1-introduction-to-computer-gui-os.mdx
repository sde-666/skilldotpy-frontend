# NIELIT CCC Complete Study Guide & Master Shortcuts

The **Course on Computer Concepts (CCC)** is the essential government-certified digital literacy qualification under NIELIT.

---

## 1. CCC Exam Pattern & Grading Scale

- **Total Questions:** 100 Objective Questions (MCQs & True/False)
- **Time Allowed:** 90 Minutes (Online CBT Mode)
- **Negative Marking:** **None (0 Negative Marks)**
- **Passing Marks:** 50% (50 Questions correct)

### Grading Formula
- **Grade S:** 85% and above (Superb)
- **Grade A:** 75% to 84%
- **Grade B:** 65% to 74%
- **Grade C:** 55% to 64%
- **Grade D:** 50% to 54% (Minimum Pass)
- **Grade F:** Below 50% (Failed)

## 2. Essential LibreOffice Shortcut Keys for CCC Exam

### LibreOffice Writer (Word Processor)
- **Ctrl + F12:** Insert Table (टेबल इन्सर्ट करना)
- **Ctrl + Shift + O:** Print Preview (प्रिंट प्रीव्यू)
- **Ctrl + Alt + C:** Insert Comment (टिप्पणी जोड़ना)
- **F7:** Spelling Check (वर्तनी जांच)
- **Shift + F7:** Automatic Spell Checking Toggle
- **Ctrl + F2:** Insert Fields
- **Ctrl + Shift + P:** Superscript ($x^2$)
- **Ctrl + Shift + B:** Subscript ($H_2O$)

### LibreOffice Calc (Spreadsheet)
- **Ctrl + F8:** Value Highlighting Toggle
- **Ctrl + Shift + F9:** Recalculate Hard
- **Ctrl + + (Plus):** Insert Cells / Rows / Columns
- **Ctrl + - (Minus):** Delete Selected Cells
- **Ctrl + 1:** Format Cells Dialog Box
- **Ctrl + Shift + 1:** Format as Number
- **Ctrl + Shift + 4:** Format as Currency (₹)
- **F2:** Edit active cell

### LibreOffice Impress (Presentations)
- **F5:** Start Slide Show from First Slide
- **Shift + F5:** Start Slide Show from Current Slide
- **Esc:** End Slide Show
- **Ctrl + M:** Insert New Slide

## 3. Important Banking & Digital Financial Services Topics

| Service | Full Form / Code | Organization / Key Feature |
| :--- | :--- | :--- |
| **UPI** | Unified Payments Interface | Developed by NPCI (National Payments Corporation of India) |
| **BHIM** | Bharat Interface for Money | Launched Dec 30, 2016 by PM Narendra Modi |
| **USSD** | Unstructured Supplementary Service Data | Code: **`*99#`** (Works without Internet connection) |
| **AEPS** | Aadhaar Enabled Payment System | Micro-ATM cash withdrawal using Biometric |
| **NEFT** | National Electronic Funds Transfer | Available 24x7x365 in batch settlements |
| **RTGS** | Real Time Gross Settlement | Min limit ₹2,00,000 for high value transactions |
| **IMPS** | Immediate Payment Service | Instant 24x7 transfer managed by NPCI |
