## 1. What is a Computer? (कंप्यूटर क्या है?)
A computer is an electronic data processing device that accepts raw data as **Input**, processes it using a set of instructions (**Program**), stores intermediate results, and produces meaningful **Output** (Information).

```text
[ Raw Data (Input) ] ──▶ [ Processing (CPU & ALU) ] ──▶ [ Meaningful Information (Output) ]
```

### Characteristics of Computers (कंप्यूटर की विशेषताएं)
- **Speed (गति):** Computes millions of instructions per second (MIPS).
- **Accuracy (सटीकता):** High degree of accuracy (GIGO - Garbage In, Garbage Out).
- **Diligence (परिश्रमशीलता):** Can work for hours without fatigue or lack of concentration.
- **Versatility (बहुमुखी प्रतिभा):** Capable of performing diverse tasks from word processing to complex calculations.
- **Storage Capacity (भंडारण क्षमता):** Stores vast amounts of data in primary and secondary memory.

## 2. Generations of Computers (कंप्यूटर की पीढ़ियां)

| Generation | Period | Core Technology | Primary Memory | Programming Language | Example Machines |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1st Gen** | 1940-1956 | **Vacuum Tubes** | Magnetic Drums | Machine Language (0s and 1s) | ENIAC, EDVAC, UNIVAC |
| **2nd Gen** | 1956-1963 | **Transistors** | Magnetic Core | Assembly & Early High Level (FORTRAN, COBOL) | IBM 1401, CDC 1604 |
| **3rd Gen** | 1964-1971 | **Integrated Circuits (IC)** | Magnetic Core / Semiconductor | High-Level Languages (BASIC, PASCAL) | IBM 360, PDP-8 |
| **4th Gen** | 1971-Present | **VLSI & Microprocessors** | Semiconductor (RAM, ROM) | C, C++, Java, Python, SQL | IBM PC, Apple Macintosh |
| **5th Gen** | Present & Future | **ULSI, AI, Quantum Computing** | High-Density SSD, Cloud Storage | Natural Languages & AI Frameworks | Supercomputers, Neural Chips |

## 3. Computer Memory Hierarchy (मेमोरी पदानुक्रम)

1. **Registers (रजिस्टर):** Located directly inside the CPU; fastest and smallest memory.
2. **Cache Memory (L1/L2/L3):** High-speed buffer between CPU and RAM.
3. **Primary Memory (RAM & ROM):**
   - **RAM (Random Access Memory):** Volatile (डेटा बिजली जाने पर मिट जाता है). Types: SRAM (Static RAM), DRAM (Dynamic RAM).
   - **ROM (Read Only Memory):** Non-volatile (स्थायी डेटा). Types: PROM, EPROM, EEPROM.
4. **Secondary Memory (द्वितीयक मेमोरी):** HDD, SSD, USB Flash Drive, Optical Discs (CD, DVD, Blu-Ray).
